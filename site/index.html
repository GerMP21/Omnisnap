See which elements render differently in every browser engine

Omnisnap captures your page in Blink, Gecko and WebKit with the browsers already on your machine, compares the geometry of every element against Chrome, and tells you what differs, why, and how to fix it. One command, nothing uploaded.

omnisnap http://localhost:3000

Elements, not pixels

Every element's box is matched across engines and compared. A table that splits its columns differently is one finding with its cause, not a thousand changed pixels.

The browsers you have

Chrome, Edge, Brave, Firefox, Safari, WebKitGTK: found on Linux, macOS and Windows, launched with clean profiles, closed when the run ends.

Reasons and fixes

Known engine behaviour is explained and set aside; what a visitor would notice is reported first, with the fix when Omnisnap recognises the cause.

Install

One binary with no runtime dependencies. On Linux x64:

curl -fsSLO https://github.com/GerMP21/Omnisnap/releases/download/{{version}}/omnisnap_{{version}}_linux_amd64
chmod +x omnisnap_{{version}}_linux_amd64 && sudo mv omnisnap_{{version}}_linux_amd64 /usr/local/bin/omnisnap

macOS and Windows binaries, and their checksums, are on the release page. Or from a package manager, binary included:

npm install -g omnisnap@{{npm_version}}
pip install omnisnap=={{pypi_version}}

On every pull request

The GitHub Action runs the capture on Linux, Windows and macOS runners, so you get real Safari without a Mac, and posts one comment on the pull request. It is report-only: it never fails the build.

on: pull_request

permissions:
  contents: read
  pull-requests: write

jobs:
  omnisnap:
    uses: GerMP21/Omnisnap/.github/workflows/report.yml@{{version}}
    with:
      start: npm ci && npm run build && npx serve -l 3000 dist
      wait-on: http://localhost:3000
      pages: |
        http://localhost:3000/

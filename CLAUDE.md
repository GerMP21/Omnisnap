# Omnisnap

## Git

- Never commit, amend, push, or open a pull request. Leave every change
  uncommitted in the working tree; the owner commits and pushes them.
- When a task is finished, give the owner:
  - a ready-to-use commit message for it (subject, blank line, body), and
  - when a branch or pull request is part of the work, the PR title and body.
- Do not treat an earlier "push it" or "commit it" as standing permission; this
  rule applies unless the owner asks for that specific action in the message
  being handled.
